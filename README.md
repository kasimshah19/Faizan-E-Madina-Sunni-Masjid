# 🕌 Faizan E Madina Sunni Masjid — Smart Mosque Management System

A full-stack MERN application for managing mosque operations, donations, events, prayer timings, volunteers, madrasa, and more.

## Tech Stack

- **Frontend:** React 19 + Vite + Tailwind CSS
- **Backend:** Node.js + Express + MongoDB
- **Auth:** JWT + OTP verification
- **Storage:** Cloudinary
- **PDF:** PDFKit (receipts & certificates)

## Project Structure

```
├── client/    → React frontend (Vite)
├── server/    → Express backend (Node)
```

## Getting Started

```bash
# Install all dependencies
npm run install:all

# Run both client and server in development
npm run dev
```

## Environment Variables

See `.env.example` in both `client/` and `server/` directories.
